# KENDO FARM

เว็บไซต์สองภาษาสำหรับแสดงผักไฮโดรโปนิกส์ที่มีวันนี้ และหลังบ้านสำหรับจัดการสินค้า ราคา จำนวนคงเหลือ และ LINE Official Account

## สิ่งที่มีในเวอร์ชันแรก

- หน้าร้านภาษาไทย/อังกฤษ พร้อมจดจำภาษาที่เลือกบนอุปกรณ์
- ผักที่มีจำนวนมากกว่า 0 ถุงจะปรากฏแก่ลูกค้า พร้อมราคาและจำนวนคงเหลือ
- ปุ่ม LINE ต่อสินค้าหนึ่งรายการ พร้อมข้อความที่กรอกชื่อผักให้อัตโนมัติ
- หน้า `/admin` สำหรับผู้ดูแลสองบัญชี: เพิ่ม แก้ไข และลบผัก รวมถึงตั้งค่าฟาร์ม
- Cloudflare D1 สำหรับข้อมูลสินค้า และ Supabase Auth สำหรับอีเมล/รหัสผ่าน

## ตั้งค่าก่อนเปิดใช้จริง

1. สร้าง Supabase project ในแผน Free และเปิด Email/Password sign-in
2. สร้างบัญชี Supabase สำหรับพ่อและแม่ แล้วเพิ่มอีเมลทั้งสองใน `ADMIN_EMAILS`
3. คัดลอก `.env.example` เป็น `.env.local` สำหรับการพัฒนา หรือเพิ่มค่าเดียวกันเป็น secret environment variables ตอนเผยแพร่:

   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
   - `ADMIN_EMAILS` — อีเมลสองรายการคั่นด้วยเครื่องหมายจุลภาค

4. ใน Supabase Auth เพิ่ม redirect URL ของเว็บไซต์ตามด้วย `/admin` สำหรับลิงก์รีเซ็ตรหัสผ่าน
5. เข้า `/admin`, เลือกประเภทบัญชี LINE เป็น **LINE ส่วนตัว** หรือ **LINE Official Account**, ใส่ LINE ID แล้วกดบันทึก จากนั้นแก้ไขชื่อผัก ราคา และจำนวนได้ทันที

LINE ส่วนตัวใช้ LINE ID เช่น `kendozaza14271` และปุ่มจะเปิดโปรไฟล์ LINE ส่วน Official Account ใช้ ID เช่น `@kendofarm` และปุ่มจะสร้าง deep link ที่เติมข้อความชื่อผักให้อัตโนมัติ

## คำสั่งสำหรับพัฒนา

```bash
npm install
npm run db:generate
npm run build
npm run dev
```

การเผยแพร่จะนำ D1 migrations ใน `drizzle/` ไปใช้กับฐานข้อมูลโดยอัตโนมัติ ห้ามใส่คีย์ Supabase ลงใน Git หรือไฟล์ที่ติดตามโดย Git
